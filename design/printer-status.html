Printer status in the editor

Study for review item 23. The editor can now ask the printer what it's doing and what tape it has. This page shows ways the printer chip at the top right could say so, and where a tape that doesn't suit the layout could be shown.

Decided, 2026-11-12, and built: option A, the state in the chip; D1, a tape that doesn't suit the layout shown in the print bar as well; no new red: trouble uses the label red #d42b20 on white (5.0 : 1), not the darker red proposed below, so the chip's trouble state has a red border on white rather than a pink fill; and the printer is asked every 5 seconds to start with.

The editor would ask every 5 seconds while its window is open and in front, after each print, and when Test connection is pressed. No animation is used: a state change is a change of words and colour.

D · A tape that doesn't suit the layout

That's about the layout as much as the printer, so it doesn't belong in the chip. Today it's a question when Print is pressed (built: "The printer has 29 × 90 mm labels loaded; this layout is for 62 mm continuous · black/red. Print anyway?"). It could also show in the print bar beforehand:

D1 · In the print bar as well recommended

29 × 90 mm labels loaded · this layout is for 62 mm

Seen while you work, so you can change the tape or the layout before pressing Print. The question when Print is pressed stays.

D2 · Only the question when Print is pressed

As built now. Nothing on screen until then.
