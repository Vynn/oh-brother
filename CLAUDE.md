# Oh-Brother

Project notes for Claude. The working preferences in `../CLAUDE.md` apply; this file adds what's particular to Oh-Brother. Before proposing anything, read `README.md`, `ROADMAP.md` and `docs/development.md`.

## Release titles

A release commit's subject is the version, then a title in the theme of the Coen brothers' film *O Brother, Where Art Thou?*, which the project's name already puns on. Lines, characters, songs and the Odyssey running through the film are all fair game: the Soggy Bottom Boys, "a man of constant sorrow", "we're in a tight spot", Dapper Dan, the sirens. The title still says what the release is about.

Chosen 2026-11-12, starting with 0.6.0. Earlier releases keep their plain titles.

| Version | Title |
|---|---|
| 0.6.0 | Printer, where art thou? Status, progress and Save PNG |

Propose a few titles for each release, to be picked from, and add the one chosen to the table.
